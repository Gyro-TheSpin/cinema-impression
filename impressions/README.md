# 感想・考察の入れ方（声メモ対応）

## 流れ
1. **声で録る** — スマホ等で感想・考察を話して録音する。ファイルを `impressions/audio/` に置くか、このチャット（Muse）に音声を送る
2. **文字起こし** — 音声をテキスト化し、`impressions/<番号>.raw.txt` に保存する
   - ⚠️ raw（原文）はそのまま記事に入れない。言い間違い・言い淀み・重複が含まれる前提
3. **編集** — 原文を読みやすく整えた「編集済み」を `impressions/<番号>.md` に作る
   - 編集の範囲：誤字の修正、言い淀みの削除、文の並び替え、段落分け
   - 編集でしないこと：言っていない感想を足す、評価を変える、観ていない場面を補う
   - チャットで頼めば Muse が編集版を作る。本人が確認・修正して確定する
4. **記事へ反映** — `python3 tools/set_impression.py --no 571 --file impressions/571.md`
5. **公開** — `python3 tools/publish.py --no 571`（編集済みの感想が入っていない記事は公開できない仕組み）

## ファイルの置き場
- `impressions/audio/` — 録音ファイル
- `impressions/<番号>.raw.txt` — 文字起こし原文（公開しない）
- `impressions/<番号>.md` — 編集済み（これだけが記事に入る）

## 編集済みファイルの形式
```
## 感想
（感想の本文）

## 考察
（考察の本文。なければこのセクションごと省略可）
```
